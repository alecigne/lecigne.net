** Music and data
:PROPERTIES:
:CREATED:  [2026-09-26 Sat]
:END:

- [[https://github.com/alecigne/somafm-recentlib][somafm-recentlib]] :: A Java library that retrieves recently played
  tracks from [[https://somafm.com/][SomaFM]].

- [[https://github.com/alecigne/somafm-song-history][somafm-song-history]] :: A Java application that archives SomaFM
  broadcasts using =somafm-recentlib=.

- [[https://github.com/alecigne/deezer-datasync][deezer-datasync]] :: A Java application that backs up my Deezer data
  to a private GitHub repository. Git may be an unusual persistence
  layer, but it gives me readable diffs and a straightforward history.

** Software
:PROPERTIES:
