#+title: lecigne.net

This is the source for my [[https://lecigne.net/][website]].

[[https://github.com/casey/just][Just]] is used to execute predefined actions -- see [[file:Justfile][Justfile]].

- =just build= will export the website to the gitignored =build/= directory
  using Emacs -- see [[file:build.el][build.el]].

- =just preview= will build the website and serve it locally on port 8000.

- =just deploy= will build the website and copy it to the webserver using
  =rclone=. It does not delete independently managed remote files.
